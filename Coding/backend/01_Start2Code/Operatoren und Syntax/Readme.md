# Operatoren und Syntax

In diesem Kapitel lernst du die wichtigsten Bausteine von C#-Code.

## Syntax-Grundlagen

- Statements enden in C# mit `;`
- Codeblöcke stehen in `{ }`
- Kommentare:
	- einzeilig: `// ...`
	- mehrzeilig: `/* ... */`

## Häufige Operatoren

### Rechnen

- `+` Addieren
- `-` Subtrahieren
- `*` Multiplizieren
- `/` Dividieren
- `%` Rest (Modulo)

### Vergleiche

- `==` gleich
- `!=` ungleich
- `<`, `<=`, `>`, `>=`

### Logik

- `&&` und
- `||` oder
- `!` nicht

### Kurzformen

- `x += 1`, `x -= 1`
- `x++`, `x--`
