# Testen und der grüne Haken

Tests geben dir Sicherheit beim Refactoring und bei neuen Features.

## Grundlagen

- ein Test prüft genau ein Verhalten
- Name beschreibt Erwartung
- Aufbau nach AAA: Arrange, Act, Assert

## Beispiel-Testname

`Add_WhenBothNumbersArePositive_ReturnsSum`

## Was testen?

- Kernlogik (Berechnungen, Regeln)
- Edge Cases (null, leere Eingaben, Grenzen)
- Fehlerpfade (ungültige Eingaben)
