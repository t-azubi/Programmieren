# LINQ und Datenabfragen

Dieses Modul zeigt, wie du mit LINQ Daten filterst, gruppierst und transformierst.

## Projekt

- `LinqPlayground/src`

## Start

```bash
dotnet run --project "LinqPlayground/src/LinqPlayground.csproj"
```

## Lernziele

- `Where`, `Select`, `OrderBy`
- `GroupBy` und Aggregationen
- Projektionen in DTO-ähnliche Objekte
